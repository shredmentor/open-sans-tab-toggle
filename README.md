# Open Sans Tab Toggle



A simple font-override extension to temporarily replace Times New Roman on a per-browser-tab basis with Open Sans.



### But... Why?



The reading materials in my Java course, while high quality and packed with valuable information, were formatted with no default <body> font. This caused the entire site to be rendered in Times New Roman, which tends to make anything harder on the eyes, especially for a technical subject like Java programming.



The simple solution: a Chrome extension that replaces the <body> font of whatever tab you're viewing with Open Sans, directly from Google Fonts. As a sans-serif font, it's designed to be very easy on the eyes.



#### How to Install \& Use It:



Drag the *open-sans-tab-toggle* folder into any directory you want (but keep it there - this needs to remain its home for the extension to work). Then in Chrome, go to the address bar and type chrome://extensions/ - from there turn on Developer mode (top right corner of the page), and then click on the "Load unpacked" on the top-left corner of the page, and navigate to the *open-sans-tab-toggle* folder you saved and finally, click Select Folder.



That's it! You may want to click on Chrome's "Extensions" puzzle-piece icon and pin the extension so it's always handy. Then just click it on any open tab and it'll toggle on Open Sans as the default <body> font; click it again to change it back.
